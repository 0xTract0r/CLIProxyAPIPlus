# CLIProxyAPI Plus

[English](README.md) | 中文

这是 [CLIProxyAPI](https://github.com/router-for-me/CLIProxyAPI) 的 Plus 版本，在原有基础上增加了第三方供应商的支持。

所有的第三方供应商支持都由第三方社区维护者提供，CLIProxyAPI 不提供技术支持。如需取得支持，请与对应的社区维护者联系。

本次同步所对应的供应商列表、赞助商与项目概览见[该版本的上游说明](https://github.com/router-for-me/CLIProxyAPI/blob/6960763455c4ac3d4828fb1736aa5de2183ccecf/README_CN.md)。本仓附有 [SDK 使用说明](docs/sdk-usage_CN.md)与[凭证加载和更新说明](docs/sdk-watcher_CN.md)。

## 贡献

该项目仅接受第三方供应商支持的 Pull Request。任何非第三方供应商支持的 Pull Request 都将被拒绝。

如果需要提交任何非第三方供应商支持的 Pull Request，请提交到[主线](https://github.com/router-for-me/CLIProxyAPI)版本。
